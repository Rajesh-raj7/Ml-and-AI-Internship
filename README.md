# Iris Flower Classification Using KNN

A Machine Learning project that uses the **K-Nearest Neighbors (KNN)** algorithm to classify Iris flowers into different species based on their sepal and petal measurements.

## 🚀 Project Overview
This project implements a KNN classification model using Python and Scikit-learn. It explores the Iris dataset, visualizes feature relationships, trains the model, and evaluates its prediction accuracy.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## 📊 Dataset
The Iris dataset contains 150 samples with four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

**Target Classes:**
- Setosa
- Versicolor
- Virginica

## ⚙️ Machine Learning Workflow
1. Load and explore the Iris dataset.
2. Visualize missing values and feature relationships.
3. Split data into 70% training and 30% testing sets.
4. Train a KNN classifier with K = 5.
5. Predict flower species using new input data.
6. Evaluate model performance using accuracy score.

## 📈 Results

| Metric | Result |
|---|---|
| Algorithm | K-Nearest Neighbors |
| Number of Neighbors | 5 |
| Training Data | 70% |
| Testing Data | 30% |
| Model Accuracy | **97.78%** |
